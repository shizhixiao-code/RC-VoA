# Data sources and access

This package releases aggregate frozen decision/diagnosis cells and verification
cost ledgers for computational replay. It does not redistribute participant-level
images or identifiers. The manuscript's source references identify:

- MILK10k development data: Tschandl et al., DOI https://doi.org/10.1016/j.jid.2025.06.1594.
- MRA-MIDAS external data: dataset DOI https://doi.org/10.71718/15nz-jv40;
  associated study DOI https://doi.org/10.1056/AIdbp2400732.
- HIBA external data: Ricci Lara et al., DOI https://doi.org/10.1038/s41597-023-02630-0.
- UQ external data: Ghahari et al., DOI https://doi.org/10.1038/s41597-025-05880-2.
- MCR-SL external data: Castro-Fernandez et al., data DOI
  https://doi.org/10.5281/zenodo.17306338; descriptor https://doi.org/10.3390/data10100166.

These source identifiers are transcribed from the accompanying manuscript.
Original image access and reuse are subject to each provider's current terms.
The aggregate replay does not require downloading any original image dataset.
For the analysis-specific variables and limitations of aggregation, see README.md.

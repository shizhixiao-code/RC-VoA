# Source Data for the integrated RC-VoA manuscript

- `all50_configurations_three_policies.csv`: all 150 matched policy rows across 50 repaired configurations, including infeasible and failed configurations.
- `diagnostic_all10.csv`: every oracle-feasible repaired configuration; source for main Fig. 3.
- `tableIII_three_witnesses.csv`: main Table III oracle and realized policy outcomes.
- `original_three_witnesses_both_budgets.csv`: the original Table III counts and 15%/20% quota intervals, transcribed from the original table; original LaTeX is retained under `archived_displays/` for verification. Protected misses are the original table's `lost` definition; they include mandatory Source-S rescues that remained missed. Oracle FP reductions and displayed heuristic rescue/miss counts are exactly as reported in the original table.
- `policy_summary.csv`: overall and conditional policy pass counts.
- `archived_displays/`: the case illustration, sensitivity/workload curve and original table/captions removed from the page-limited PDF because they duplicate displayed evidence or provide nonessential illustration. Files retain their original content, references and data-use attribution. Numbering in archived captions refers to the prior 8+5-page version, not the current manuscript.

These files preserve the evidence record; they are not additional clinical experiments or independent samples. The manuscript remains an exploratory historical-cohort analysis, with all failures retained. The removed displays are not required to interpret the main diagnostic figure or apply the full criterion, which remain in the 12-page manuscript and supplement.
